P7DapperBank

ASP.NET Core 6 MVC ve Dapper ORM ile geliştirilmiş, milyonlarca kayıt üzerinde anlık filtreleme ve sayfalama yapabilen yüksek performanslı bir banka yönetim panelidir.

Özellikler

Dashboard — Task.WhenAll ile paralel async sorgular; istatistik kartları, pasta grafik, çubuk grafik, son işlemler 

5 entity için tam CRUD — Müşteri, Hesap, Banka, İşlem Tipi, İşlem

Sunucu taraflı filtreleme — DynamicParameters ile SQL Injection korumalı dinamik WHERE

Sayfalama — PagedResult<T> + PaginationViewComponent, sayfa değişiminde filtreleri korur

GET form filtreleri — filtreler URL'de, bookmark ve geri tuşu desteği

Covering index'ler — 3,3 milyon satırda hızlı agregasyon
